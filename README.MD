# Quora Question Pair Detection Using DistilBERT

## Project Overview
This project uses Natural Language Processing (NLP) and the DistilBERT transformer model to identify whether two Quora questions have the same meaning.

## Objective
The main objective is to classify a pair of questions as duplicate or non-duplicate questions.

## Technologies Used
- Python
- Natural Language Processing (NLP)
- DistilBERT
- Transformers
- PyTorch
- Pandas
- Scikit-learn

## Project Workflow
1. Load and explore the question-pair dataset.
2. Prepare the data for model training.
3. Split the dataset into training and validation sets.
4. Fine-tune the DistilBERT model.
5. Evaluate the model.
6. Predict whether two questions are duplicates.

## Model
DistilBERT is a transformer-based language model used to understand the semantic meaning of text and classify question pairs.

## Dataset
The project uses a Quora question-pair dataset. The dataset must be available at the appropriate path before running the code.

## How to Run
1. Install the required Python libraries.
2. Download or provide the dataset.
3. Update the dataset paths in the code.
4. Run the Python script in a suitable Python environment.

## Applications
- Duplicate question detection
- Question similarity analysis
- NLP-based text classification
